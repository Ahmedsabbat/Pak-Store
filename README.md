# Pak Store

A responsive e-commerce store frontend built with HTML, CSS, and JavaScript. Products are loaded dynamically from an external GraphQL API, with search, category filtering, cart management, and checkout functionality.

## Features

* Dynamic products from API
* Product search
* Category filtering
* Add products to cart
* Quantity limit of 5 per product
* Remove products from cart
* Automatic subtotal and grand total calculation
* Checkout form with validation
* Responsive design for mobile and desktop
* Error handling for API requests

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* DOM Manipulation
* Fetch API
* Async/Await
* GraphQL API
* Array Methods
* Responsive CSS
* Git & GitHub

## API

Products are fetched from the Mock Shop GraphQL API.
